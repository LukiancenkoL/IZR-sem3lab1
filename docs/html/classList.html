Detailed Description

template<typename T>
class List< T >

Abstract base class representing a list-like container.

This class defines the common interface for list operations such as inserting, removing, accessing elements, and checking the list state. Concrete implementations (e.g., linked list, dynamic array) must override all pure virtual methods.

Template Parameters
TType of stored elements.
