\doxysubsection{Detailed Description}
\subsubsection*{template$<$\mbox{\hyperlink{classArrayList}{typename}} \mbox{\hyperlink{classArrayList}{T}}$>$\newline
class List$<$ T $>$}
Abstract base class representing a list-\/like container. 

This class defines the common interface for list operations such as inserting, removing, accessing elements, and checking the list state. Concrete implementations (\doxylink{classArrayList_a77ba51ae82bb2246563af5c4d64d438e}{e.\+g}., linked list, dynamic array) must override all pure virtual methods.
